# 🌍 WorldAir Chat - Global AQI & Weather Platform

> An international real-time air quality & weather monitoring platform with multilingual community chat.

### 🚀 Live Features
- **Real-time AQI** - Live Air Quality Index for 200+ cities
- **Global Weather** - Temperature, humidity, wind data
- **Multilingual Chat** - Community discussion with translation
- **City Search** - Search any city worldwide
- **Climate Awareness** - Health recommendations based on AQI

### 🛠️ Tech Stack
- Frontend: React.js, HTML5, CSS3
- APIs: OpenWeather API, Translation API
- Deployment: Vercel / Netlify
- Version Control: Git & GitHub

### 📊 Why This Project?
Air pollution is a global crisis. This platform helps people check air quality before going out and connect with a global community to raise climate awareness.
